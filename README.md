# 經彩青春 SET｜國小版・樂樂怎麼了？

依照《補給站國小.docx》情境腳本製作的月經教育數位互動教材，採用「逐頁故事 → 三選一問題 → 立即回饋 → 知識徽章」的遊戲形式。畫面為全新珊瑚粉／淡紫色設計，延續先前教材的清楚閱讀節奏與手機友善操作。

## 教材內容

- 國小版，故事人物：樂樂、小琪、大明、護理師。
- 對應原始腳本 **23 頁**：封面 1 頁、故事／題目／回饋 21 頁、結尾 1 頁。
- **10 道三選一互動題**，答對後才能前進，答錯可直接再試。
- 每答對一題獲得一枚經彩星星，接著解鎖相應「Good Job」知識回饋。
- 完成全部 10 題後，才顯示稱號「平權小超人」與青春密碼 **5200**。
- 提供上一頁、重新開始、手機響應式排版與密碼複製。
- 角色與情境視覺目前由網頁程式呈現，不需要外部圖片；未來可逐頁替換為正式插畫。

## GitHub Pages

在儲存庫的 **Settings → Pages → Build and deployment**，選擇 **Deploy from a branch**；分支 **main**、資料夾 **/(root)**，儲存。

網站預定網址：https://kaoelvmpvm.github.io/jingcai-youth-interactive-learning-es/

*注意：Repository 中有網頁檔案並不代表 Pages 已經啟用。若網頁出現 404，請先確認 Pages 的部署設定。*

## 檔案結構

- `index.html`：首頁、故事／答題／回饋畫面、完成畫面。
- `assets/style.css`：精緻粉彩 UI、角色示意、響應式介面與動畫。
- `assets/app.js`：逐頁流程、判題、進度、返回、重新開始與密碼複製。
- `data/scenes.js`：對應腳本的 21 個內頁節點、10 題題目／答案／回饋與結局。
- `tests/scenes.test.cjs`：資料完整性及通關規則的測試。

## 測試

本機安裝 Node.js 20 以上，在專案資料夾執行：

```bash
node --test tests/scenes.test.cjs
```

## 調整教材

若需要修改文字與正確答案，優先修改 `data/scenes.js`。各關題目包含 `qid`、`question`、`options`、`correct`，其中正確答案為由 **0** 開始的陣列索引（0=A、1=B、2=C）。

腳本文字以提供的原始文件為主，內容若未來要依教學或專家審查進行修訂，需另行確認。
