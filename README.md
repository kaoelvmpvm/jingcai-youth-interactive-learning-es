# 經彩青春 SET｜國小篇・樂樂怎麼了？

依照《「經」彩青春 Set－國小篇（調整版）》改編的角色舞臺式互動教材。保留定稿劇本 **22 幕（首頁 1 幕、互動劇情 21 幕）**、10 道三選一互動挑戰、Good Job 知識回饋與通關密碼 **0451（你是唯一）**。

## 遊戲畫面與玩法

- 參考「1-3 青春補給－不迷路」的角色舞臺形式：立繪、氣泡、出場焦點、完整劇情台詞與場景背景。
- 四個角色：樂樂、小琪、大明、護理師。角色以原創 SVG 向量插圖呈現，支援清晰放大。
- 逐幕設定人物在場清單、發言焦點、情緒標示。沒有臺詞不等於不在場。
- 桌面版在角色上方顯示對話氣泡；手機版改成精簡舞臺發言提示，**全部正式對話仍在下方完整保留**。
- 10 題 A／B／C 選擇題，答錯可立即重試，答對才能進入下一幕。
- 每道題答對後，下一幕呈現原稿 Good Job 知識回饋。全部題目完成後才可領取密碼。
- 支援上／下一幕、複製通關密碼、重新開始確認、本分頁重新整理後繼續進度及減少動畫偏好。

## 程式架構

| 檔案 | 功能 |
| --- | --- |
| index.html | 首頁、故事舞臺、對話、互動題、完成頁 |
| assets/style.css | 角色舞臺、場景、RWD、回饋視覺 |
| assets/app.js | 劇情導航、角色顯示、題目判斷、進度、密碼複製 |
| assets/characters/*.svg | 四名角色的原創向量立繪 |
| data/scenes.js | **正式劇本唯一來源**；含全部文案、題目、ABC 選項與正確答案 |
| data/presence.js | 逐幕場景位置、人物清單、發話焦點、情緒設定 |
| tests/scenes.test.cjs | 劇本、21 幕角色配置、答案、通關與素材完整性測試 |

## 修改原則

劇本內容只改 data/scenes.js；角色出現與舞臺構圖只改 data/presence.js。不要根據「該頁哪些人物發話」來推定「哪些人物在場」。劇本文字應經教學端確認後再修改。

本教材可在 GitHub Pages 靜態網站執行，不需要帳號、資料庫或 API 金鑰。使用 sessionStorage 暫存**同一分頁**的答題進度；關閉分頁不保證保留。操作重新開始會清除該暫存紀錄。

## 驗證

node --test tests/scenes.test.cjs
